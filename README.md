# Space Fighter

yo, built this arcade shooter from scratch using pygame. layout is clean, no heavy classes, just pure functional code. perfect for anyone trying to see how game loops, basic particle physics, or a boss state machine works. 

### Controls

**Player 1**
* A / D -> Move left & right (clamped bounds so U don't get stuck)
* SPACEBAR -> Shoot lasers (has cooldown so Ur not spamming 60 bullets a sec lol)

**Player 2**
* LEFT / RIGHT arrows -> Move left & right (same clamped bounds as P1)
* UP arrow -> Shoot lasers (same as P1, one shot per press)

**Menu / Game Over**
* SPACEBAR -> Start the game or try again after Game Over

**Co-op rules**
* Both players play at the same time on the same screen
* Score and lives are shared, so watch out for each other
* Double shot powerup is shared too, if one of U grabs it both of U get it

## Theme
I have chosen this theme (CO-OP) because there are two space ships working together to kill the boss and get high scores, and any mistake from anyone of them will lead all to lose so this is a coorporation to win, there will be no sacrifice.

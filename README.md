# Space Fighter

![Python](https://img.shields.io/badge/Python-3.11-blue) ![Pygame](https://img.shields.io/badge/Pygame-2D-green)

A 2 player co-op space shooter made with Python and Pygame.

## About
Space Fighter is an arcade shooter where two players share one screen. Enemies fall faster as your score goes up, and at 150 points a boss shows up. Kill it and the game goes on with even faster enemies. It's all plain functions, no classes, so it's easy to read if you want to see how a game loop, simple particles and a boss fight work.

## Theme
The theme is CO-OP. Two ships work together to kill the boss and get a high score. Score and lives are shared, so one mistake from either player hurts both of you. You win together or lose together.

## What's in the game
- 2 players on the same keyboard at the same time
- 4 levels, then a boss fight with a health bar
- Double shot powerup (shared between both players)
- Pixel art ships, enemies and boss drawn in code
- Explosion particles and sound effects

## Getting Started

### Play without installing Python
1. Go to the **Releases** page on the right side of this repo
2. Download the file for your system (Windows, Linux or Mac)
3. Run it and press SPACEBAR in the menu to start

Windows may show a SmartScreen warning because the game is not signed. Click "More info" then "Run anyway". On Linux and Mac, extract the file and run `./SpaceFighter` in the terminal.
